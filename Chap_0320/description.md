1-1. 자료구조란?
    : 컴퓨터의 자료를 정리하는 구조

    1-2-1. 자료구조의 선형성

        선형: 자료를 일렬로 나열할 수 있는 구조
            예: 스택, 큐, 덱, 리스트 ...

        비선형: 한 줄로 나열하기 어려운 복잡한 관계
            예: 트리, 그래프, 집합 ...
    
    1-2-2. 자료구조의 구현 방법

        배열 구조: 모든 자료가 인접한 메모리 공간에 저장

        연결된 구조: 흩어져있는 자료들을 연결하여 하나로 관리

1-2. 알고리즘이란?
    
    1-2-1. 알고리즘의 조건

        1. 입력: 모호하지 않고 잘 정의된 입력
        2. 명확성: 각 명령어의 의미가 명확해야함
        3. 언어 독립성: 프로그램 언어와 상관없음
        4. 출력: 명확히 정의된 1개 이상의 출력
        5. 유환성: 반드시 종료되어야 함
        6. 유효성: 명령어들은 현재 실행 가능한 연산
    
    알고리즘의 기술 방법

        유사 코드(특정 프로그래밍 언어가 아님)
            시험문제가 알고리즘 구현이라면 유사코드로 제출해야됨

1-3. 추상 자료형
    
    데이터 타입을 추상적으로(수학적) 정의한것
    자료형에서 필수적인 특징만 골라서 단순화

1-4. 알고리즘의 성능 분석

    효율적인 알고리즘이란: 실행시간이 짧으면서(시간 효율성), 컴퓨터의 자원들을 적게 사용(공간 효율성)
    
    1-4-1. 알고리즈의 성능분석 기법
        
        실행 시간을 측정

            1. 가장 단순한 방법: 실행시간 = (종료시각 - 현재시각)
                일단 반드시 구현해야 함.
                같은 조건의 하드웨어, 소프트웨어 환경을 써야됨 (가장 크리티컬)(사실상 이 방법을 안쓰는 이유)

        알고리즘의 복잡도를 분석

            1. 알고리즘의 연산 횟수를 대략적으로 계산

```c
#include <time.h>
#include <stdio.h>

int main() {
    clock_t start = clock();
    
    // 측정할 코드 작성
    
    clock_t end = clock();
    double elapsed = (double)(end - start) / CLOCKS_PER_SEC;
    
    printf("실행 시간: %f초\n", elapsed);
    return 0;
}
```
            2. 점근적 표기
                복잡도 함수를 최고차항만으로 계수없이 표현
                lim->무한 과 비슷한 스탠스
                증가속도에만 관심을 갖는다.

            - 빅 오 (얘만 알면 됨) (상한)
            - 빅 오메가 (하한)
            - 빅 세타

1-5. 빅 오 표기법: O(g(n))

    1-5-1.  빅 오 표기법의 정의

        알고리즘의 최악의 경우(worst case) 시간 복잡도를 나타냄
        
        n이 충분히 클 때, f(n) ≤ c·g(n)을 만족하는 양의 상수 c가 존재하면
        f(n) = O(g(n))으로 표현
        
        최고차항의 영향이 가장 크므로 최고차항만 남기고 계수는 제거

    1-5-2. 
        데이터 배치에 따라서 최악 부터 최선까지 다양한 경우가 나오지만, 대부분 최악의 경우로 알고리즘 복잡도를 계산한다.

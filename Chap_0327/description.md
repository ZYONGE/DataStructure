# Chap_0327 학습 정리

이 챕터의 코드는 배열, 포인터, 구조체, 전치 연산을 통해 자료구조의 기본 표현 방법을 연습하는 데 목적이 있다.

## 1. 배열의 개념과 메모리 크기 (`array.c`)

- 배열은 같은 자료형의 데이터를 연속된 메모리에 저장하는 선형 자료구조이다.
- 배열은 `<인덱스, 값>` 형태로 접근하며, 인덱스를 통해 $O(1)$ 시간에 요소 접근이 가능하다.
- `sizeof(배열) / sizeof(원소)`로 배열의 전체 원소 수를 구할 수 있다.

핵심 학습 포인트

- 기본 자료형(`char`, `int`, `float`, `double`)의 바이트 크기 이해
- 배열 전체 크기와 배열 원소 1개의 크기 차이 이해
- 정적 배열에서 원소 수 계산 방법 습득

## 2. 함수 인자 전달 방식 (`doublearray.c`)

- 변수는 값 전달(Call by Value)되어 함수 내부 변경이 원본에 반영되지 않는다.
- 배열은 함수 인자로 전달될 때 첫 원소의 주소가 전달되므로(포인터), 함수 내부 변경이 원본에 반영된다.
- 포인터 인자(`int *x`)를 사용하면 일반 변수도 원본 값을 직접 수정할 수 있다.

핵심 학습 포인트

- `reset_variable(x)`와 `reset_variable_reference(&x)` 결과 비교
- `reset_array(iA, len)`를 통한 배열 원본 변경 확인
- 값 전달과 주소 전달의 동작 차이 이해

## 3. 2차원 배열과 전치 행렬 (`matrix.c`)

- 2차원 배열은 행렬을 표현하는 기본 자료구조이다.
- 전치 행렬은 $(i, j)$ 원소와 $(j, i)$ 원소를 교환해 생성한다.
- 정사각 행렬에서 대각선 위쪽만 순회하며 교환하면 중복 연산 없이 전치를 수행할 수 있다.

핵심 학습 포인트

- `#define ROWS`, `#define COLS`를 통한 고정 크기 배열 설계
- 이중 반복문과 인덱스 제어(`j = i + 1`)로 효율적인 교환 구현
- 행렬 출력 함수와 연산 함수 분리(기능 분해)

## 4. typedef와 구조체, 참조 전달 (`typedef.c`)

- `typedef struct { ... } Complex;`는 복합 데이터를 하나의 사용자 정의 자료형으로 추상화한다.
- 구조체를 함수에 값으로 전달하면 복사본이 전달되어 원본이 유지된다.
- 구조체 포인터를 전달하면 원본 구조체를 직접 수정할 수 있다.

핵심 학습 포인트

- 구조체 기반 데이터 모델링(복소수: 실수부/허수부)
- Call by Value vs Call by Reference를 구조체로 검증
- 포인터 연산자 `->` 사용법

## 5. 희소 행렬의 배열 표현 (`typedef_array.c`)

- 희소 행렬은 0이 아닌 값만 저장하면 메모리를 절약할 수 있다.
- `Elem {row, col, value}` 구조체 배열로 희소 행렬의 유효 원소만 저장한다.
- 전치 연산은 각 원소의 `row`와 `col`만 교환하면 구현 가능하다.

핵심 학습 포인트

- 구조체 배열을 이용한 희소 데이터 표현
- 일반 2차원 배열 방식과 희소 행렬 방식의 차이 이해
- 데이터 출력 함수와 변환 함수 분리

## 6. 다항식의 배열 표현과 최적화 (`poly.c`)

- 다항식은 계수 배열 `coeff[i]`로 표현하며, `coeff[i]`는 $x^i$ 항의 계수이다.
- 예: $3 + 6x + 10x^5$는 `coeff = {3, 6, 0, 0, 0, 10}`으로 표현된다.
- `evaluate()` 함수는 **홀너의 방법(Horner's method)**을 사용해 $O(n)$ 시간에 다항식 값을 계산한다.
- 홀너의 방법: $p(x) = (((...((a_n \cdot x + a_{n-1}) \cdot x + a_{n-2}) \cdot x + ...) \cdot x + a_1) \cdot x + a_0$
- 이 방법으로 $x^i$를 매번 계산하지 않고 누적 곱셈(`mul *= x`)으로 효율을 높인다.

핵심 학습 포인트

- 수학적 대상(다항식)을 배열 구조로 추상화하는 방법
- `add()` 함수로 다항식 덧셈 구현 (두 다항식 중 높은 차수까지 계산)
- 홀너의 방법을 통한 다항식 평가 최적화
- 0이 아닌 항만 출력하는 `print_poly()` 함수
- 단순 반복문만으로 복잡한 수학 연산을 효율적으로 처리

## 7. 희소 다항식의 구조체 배열 표현 (`sparsepoly.c`)

- 희소 다항식은 0이 아닌 항(계수≠0)만 배열에 저장하여 메모리를 절약한다.
- `Term {exp, coef}` 구조체로 각 항을 표현하며, 최고차수부터 내림차순으로 정렬된 상태로 유지한다.
- 예: $10x^5 + 6x + 3$은 `{(5, 10), (1, 6), (0, 3)}` 형태로 저장된다.
- `add()` 함수는 **병합 정렬(merge) 방식**을 사용해 두 희소 다항식을 효율적으로 덧셈한다.
- 병합의 시간복잡도: $O(m + n)$ (일반 배열의 덧셈은 $O(\max(m,n))$ 또는 $O(n^2)$)

핵심 학습 포인트

- 희소 다항식의 개념과 메모리 효율성 (0이 많은 항들을 저장하지 않음)
- 정렬 상태 유지의 중요성 (내림차순 순서로 항들을 정렬)
- 병합 정렬 방식의 덧셈 알고리즘 (두 포인터를 이용한 선형 병합)
- 차수가 같은 항을 만났을 때 계수를 더하는 로직
- 다항식 평가는 여전히 각 항별로 $O(1)$에 계산 가능

## 8. 전체 요약

이 코드들로 다음 내용을 연결해서 이해할 수 있다.

- 배열은 연속 메모리 기반의 선형 자료구조이며 인덱스 접근이 빠르다.
- 함수 호출 시 값 전달과 주소 전달은 동작과 결과가 다르다.
- 2차원 배열은 행렬 표현에 적합하고, 전치 연산은 인덱스 교환으로 구현된다.
- `typedef`와 구조체는 현실 데이터를 추상화해 자료구조로 다루게 해준다.
- 희소 행렬은 구조체 배열로 표현하면 공간 효율이 높아진다.
- 다항식 같은 수학적 개념도 배열과 구조체로 표현 가능하며, 알고리즘(홀너의 방법)으로 효율을 높일 수 있다.
- 희소 다항식은 메모리 효율뿐 아니라 알고리즘 효율(병합 방식 덧셈)도 동시에 개선한다.

# 리스트(List) 자료구조

## 1. 리스트의 정의
리스트는 데이터를 순서대로 나열한 선형 자료구조입니다. 집합과 달리 원소 간의 순서가 유지되며, 동일한 데이터의 중복 저장을 허용합니다.

## 2. 작동 방법
리스트는 크게 두 가지 방식으로 구현됩니다:
- **순차 리스트 (Array List):** 배열을 이용하여 물리적으로 연속된 메모리 공간에 데이터를 저장합니다.
- **연결 리스트 (Linked List):** 노드들이 포인터를 통해 논리적으로 연결되어 메모리 상에 흩어져 저장됩니다.

주요 연산으로는 데이터의 삽입(Insert), 삭제(Delete), 탐색(Search), 참조(Get) 등이 있습니다.

## 3. 인덱스(Index) 개념
인덱스는 리스트 내에서 데이터의 위치를 나타내는 번호입니다. 일반적으로 0부터 시작하며(Zero-based indexing), 인덱스를 통해 특정 위치의 데이터에 직접 접근(Random Access)할 수 있습니다.

## 4. 구현 파일 해설

### 4.1. 순차 리스트 (ArrayList.c, .h)
- **구조체 정의:** 배열과 현재 저장된 데이터의 개수(`size`)를 포함합니다.
- **장점:** 인덱스를 통한 조회 속도가 매우 빠릅니다 ($O(1)$).
- **단점:** 데이터 삽입 및 삭제 시 요소들을 뒤로 밀거나 앞으로 당기는 과정이 필요하여 속도가 느립니다 ($O(n)$). 배열의 크기가 고정되어 있어 확장이 어렵습니다.

### 4.2. 연결 리스트 (LinkedList.c, .h)
- **구조체 정의:** 데이터 필드와 다 음 노드의 주소를 가리키는 포인터 필드(`next`)를 가진 노드(Node) 구조를 사용합니다.
- **장점:** 삽입과 삭제 시 포인터만 변경하면 되므로 효율적입니다. 메모리 공간을 동적으로 할당하여 크기 제한이 없습니다.
- **단점:** 특정 인덱스의 데이터를 찾기 위해 첫 노드부터 순차적으로 탐색해야 하므로 조회 속도가 느립니다 ($O(n)$). 포인터 저장을 위한 추가 메모리가 필요합니다.

### 4.3. 이중 연결 리스트 (DoubleLinkedList.c, .h)
- **구조체 정의:** 데이터 필드와 다음 노드(`next`) 및 이전 노드(`prev`)를 가리키는 포인터 필드를 가진 노드 구조를 사용합니다.
- **장점:** 양방향 탐색이 가능하여 특정 노드에 빠르게 접근할 수 있습니다. 삽입과 삭제가 더욱 유연합니다.
- **단점:** 단일 연결 리스트보다 더 많은 메모리를 사용합니다. 구현이 복잡할 수 있습니다.

## 5. 요약 및 비교
| 특징 | 순차 리스트 (Array List) | 연결 리스트 (Linked List) |
| :--- | :--- | :--- |
| **접근 속도** | 매우 빠름 ($O(1)$) | 느림 ($O(n)$) |
| **삽입/삭제** | 느림 ($O(n)$) | 빠름 ($O(1)$ - 위치를 알 때) |
| **메모리 활용** | 정적 (연속적) | 동적 (불연속적) |

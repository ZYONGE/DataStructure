# DataStructure

Practice the basic concepts of data structures.

## Tech Stack

- C
- Terminal / Command Line

## Feature
- Implementation of basic data structures
- Understanding memory management in C

## How to Compile and Run

### 1. Windows
Use **MinGW / WSL / GCC**
```bash
gcc main.c -o main
main.exe
```
### 2. MacOS / Linux
```bash
gcc main.c -o main
./main
```
